| 02 First, what is hangman? | Just like in Battleship, the greedy strategy does a very solid job of quickly finishing a game of hangman.  However, unlike in the Battleship video, the number of words is small enough that we don’t have to stop with the greedy algorithm.  If we examine the possibilities more closely, we can do better, ending with a strategy that is optimal or close to optimal, at least if the words are chosen at random. Our approach looks like this.  We start at the top of one of these tree diagrams we’ve been drawing.  We need to figure out which choice of first letter will lead us to the smallest average number of misses.  How do we do this?  Well, we just try every choice of first letter and see every situation we can encounter. Now, for each situation we can get after the first guess, we again need to figure out the best letter to play there.  We again check every letter (except for the one we’ve already checked), check every situation we encounter, and we keep going.  We eventually get far enough down the tree that we can actually just count the average number of guesses for each case and take the best one. Once we’ve done that, we’ve solved that position in hangman.  We can then work our way back up the tree, using our solved positions at lower levels to help solve the positions at upper levels, until we work our way back up the tree to solve the whole game for a given word length. It may sound like there would be an absurd number of things to check, but there’s a lot that we can simplify here.  First, we’ll often see the same positions come up multiple times.  If we guess the same letters in a different order, we’ll end up with the same strategy, so if we solved the position once, we don’t have to do it again. We also only care about solutions that might be optimal, so there are a lot of bad guesses, like letters that can’t be in the word, that we don’t actually have to check.  I put a more detailed writeup about this in my blog post linked in the description if people are interested. As we’ve already seen, even the length of the game can depend a lot on the length of the word that we’re using. But the main point to make here is this. | So here’s our approach.  We’re going to assume that our opponent is using a version of our greedy guessing strategy, since the optimal one is hard to compute every time.  In the spirit of treating each word length like a different game, we’ll come up with a strategy for every word length separately.  Otherwise, we would only ever play with 3-letter words. We’re going to start by choosing words completely at random \- every word equally likely.  Then, we’ll try making some words more or less likely by changing how likely certain combinations of a single letter are to appear.  Every time we try out some new frequencies, we rerun the guessing strategy to give it the chance to adjust to our changes.  We then see if the guesser gets more or fewer misses on average.  If the guesser has more misses than before, we keep our changes.  Otherwise, we go back to what we had before.  Once we reach a point where we can no longer make any changes that will increase the average misses, we have our final strategy. | Reference blog post for more information |
